**Descrição**

O programa Boletim de uma Pequena Turma foi desenvolvido em linguagem C para facilitar o registro e a análise das notas dos estudantes de uma turma. Ele permite calcular as médias individuais, verificar a situação de cada estudante e obter um resumo do desempenho geral da turma.

**Funcionalidades**

- Cadastro de estudantes e leitura de três notas por estudante.

- Validação dos nomes e das notas.

- Cálculo das médias individuais e da média geral da turma.

- Exibição de uma tabela com nomes, notas, médias e situações.

- Identificação do estudante com a maior média, incluindo empates.

- Calcula e exibe a média geral da turma.

- Identifica a maior média e exibe o nome de todos os estudantes empatados nessa média.


**Compilação e execução**

O programa foi desenvolvido em linguagem C e utiliza o arquivo main.c

O programa pode ser compilado e executado em compiladores online ou em ambientes de desenvolvimento, como o Visual Studio Code (VS Code), desde que possuam um compilador C. 


Em compiladores online, basta selecionar a linguagem C, inserir o código-fonte do arquivo main.c e clicar em Run para compilar e executar o programa. Em ambientes como o Visual Studio Code (VS Code), é necessário abrir o arquivo e utilizar um compilador C para compilar e executar o código.


Após iniciar o programa, informe a quantidade de estudantes, seus nomes e as três notas de cada um para visualizar os resultados.
